# FinOps Methodology

## Assessment Approach

This toolkit uses a simple five-step approach:

1. **Collect** billing, resource inventory, and utilization data
2. **Normalize** spend by project, service, owner, and environment
3. **Analyze** cost drivers, anomalies, and waste patterns
4. **Recommend** optimization actions with saving estimate and risk level
5. **Govern** with budget alerts, labels, and monthly review cadence

## Recommendation Prioritization

| Priority | Criteria |
|---|---|
| P1 | High saving, low risk, quick implementation |
| P2 | High saving, medium risk, requires owner validation |
| P3 | Medium saving or requires architecture change |
| P4 | Low saving, optional improvement |

## Savings Categories

- Rightsizing
- Scheduling
- Storage lifecycle
- BigQuery query optimization
- Logging volume control
- Committed use discount review
- Resource cleanup
