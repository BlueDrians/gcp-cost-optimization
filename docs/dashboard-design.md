# Dashboard Design

## Dashboard Pages

### 1. Executive Overview
- Total monthly cost
- Budget variance
- Estimated monthly savings
- Top 5 cost drivers
- Savings by recommendation category

### 2. Service Breakdown
- Cost by service
- Cost by SKU
- Cost trend by day
- Service-level growth indicator

### 3. Project and Environment Analysis
- Cost by project
- Cost by environment
- Cost by team or owner label
- Shared services allocation

### 4. Rightsizing and Waste Reduction
- Underutilized VM candidates
- Idle resources
- Storage lifecycle opportunities
- BigQuery optimization opportunities

### 5. Budget Monitoring
- Budget vs actual
- Forecast vs budget
- Alert threshold status
- Action owner

## Suggested Looker Studio Controls

- Date range
- Project
- Environment
- Service
- Team / owner label
- Recommendation risk level
