# Presales One-Pager

## Solution Name

GCP Cost Optimization Dashboard and FinOps Review

## Customer Challenge

Many organizations adopt cloud quickly, but cost visibility and ownership often lag behind. This leads to unused resources, budget overruns, unclear chargeback, and limited executive visibility

## Proposed Solution

Implement a cost optimization dashboard based on Cloud Billing export, BigQuery analysis, budget guardrails, and rightsizing recommendations

## Business Outcomes

- Improve cloud spend visibility
- Identify quick-win savings opportunities
- Reduce budget overrun risk
- Establish monthly FinOps governance
- Align cloud cost with business owners

## Deliverables

- Cost dashboard
- BigQuery SQL views
- Executive summary
- Rightsizing recommendation list
- Budget alert configuration
- Monthly review template

## Target Audience

- CIO / CTO
- Finance team
- Cloud platform team
- Application owners
- Presales and solution architects
